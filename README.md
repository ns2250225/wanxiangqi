# 王者万象棋 · 网页复刻版

一个使用原生 HTML、CSS 和 JavaScript 实现的六人自走棋网页游戏。项目包含棋手选择、英雄商店、阵容布置、自动战斗、装备与天赋、暗标拍卖和完整结算流程，并配有 AI 生成的英雄、棋手、卡牌、召唤物与战场素材。

> 本项目为非官方学习与交流项目，与相关游戏及其权利方无隶属或授权关系。

## 游戏特色

- 六名玩家同局竞技，其他玩家由 AI 控制
- 85 位英雄，具有不同阵营、职业、技能和成长路线
- 10 位棋手及对应的专属能力
- 英雄购买、合成、升级、觉醒与阵容布置
- 装备、效果牌、天赋和召唤物系统
- 自动战斗及战斗回放
- 第 3、7、11 回合后的暗标拍卖
- 完整排名、生命值和经济循环
- AI 生成的独立英雄头像与游戏美术素材
- WebP 按需加载，降低网页首次加载体积

## 玩法简介

每回合会发放能量，未使用的能量可以保留。玩家可以在商店购买英雄牌和效果牌、刷新或锁定商店，并通过拖放将英雄部署到棋盘。

相同英雄可以合成并提升等级。英雄在战斗中会自动移动、攻击、恢复法力并释放技能。战败方会根据回合数及敌方存活英雄数量受到伤害，最后存活的玩家获胜。

游戏中的主要关键词包括：登场、整备、开团、牺牲、退场、凯旋、败阵、夺取、闪现、临时等级和转瞬。

## 本地运行

项目不依赖构建工具，可以直接使用任意静态文件服务器运行。

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

也可以使用 Node.js 静态服务器或部署到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 等平台。

## 测试

项目包含无界面模拟测试，可使用 Node.js 执行：

```bash
node test/sim.js 1
```

参数 `1` 表示为每位棋手运行一轮完整模拟。测试输出会包含平均回合数、战斗时长、超时战斗和受保护错误数量。

## 项目结构

```text
wanxiangqi/
├─ assets/generated/   # PNG 原图与网页使用的 WebP 游戏素材
├─ css/style.css       # 页面布局和视觉样式
├─ js/
│  ├─ ai.js            # AI 决策
│  ├─ art.js           # 素材加载、图集裁切和缓存
│  ├─ battle.js        # 战斗模拟与播放
│  ├─ content.js       # 技能、天赋和棋手内容
│  ├─ data.js          # 英雄、效果牌和装备数据
│  ├─ game.js          # 商店、经济、回合和结算规则
│  ├─ ui.js            # 页面渲染和交互
│  └─ util.js          # 通用工具函数
├─ test/               # 模拟与浏览器测试脚本
└─ index.html          # 页面入口
```

## 素材加载优化

- 首屏仅预加载棋手头像图集
- 英雄图集根据商店和阵容中实际出现的英雄按需加载
- 卡牌、召唤物和战斗背景在进入游戏后加载
- 网页运行使用压缩后的 WebP，PNG 原图同时保留在仓库中
